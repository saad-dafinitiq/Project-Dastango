# Music licences

Every track in this folder is an original piece composed and synthesised by this project's own script,
`scripts/make_music.py` (chords, bass, arpeggio and pads from plain oscillators). No sample, recording or
third-party material is in them, so there is no one else's licence to honour. They are released under
**CC0 1.0 Universal** (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/): use them
for anything, with no credit needed.

Re-running the script reproduces them exactly (fixed seeds). Licensed recordings can be added by putting the file
here and adding a row to `library.json` **and** a line below with its source URL and licence.
